## ملاحظات مهمة
- **الشعار:** لم يُرفق ملف شعار رسمي؛ لذلك المشهد 9 يستخدم تكويناً نصياً مؤقتاً (NET / BUSINESS SOLUTIONS / نت لحلول الأعمال). يُستبدل بالشعار الأصلي في `S9` داخل `film/index.html` (رسم الصورة مكان `wm`).
- **التعليق الصوتي:** الموسيقى والمؤثرات مُولّدة برمجياً (`audio.py`). التعليق الصوتي البشري غير مُضمَّن، ويُضاف لاحقاً مع خفض الموسيقى تحته (ducking). نصوص التعليق تظهر كطباعة حركية في الفيلم.
- **معلومات التواصل:** لم تُذكر في الملف، فلم تُضَف.

## إعادة التصدير
```bash
node render.js preview ./prev 4,24,84          # لقطات معاينة
node render.js range seg.mp4 0 2160            # الفيلم كاملاً 4K (يمكن تقسيمه على عدة عمليات)
python3 audio.py music.wav
ffmpeg -i seg.mp4 -i music.wav -c:v copy -c:a aac -b:a 320k -af loudnorm=I=-16:TP=-1.5 -shortest NET_film_4K.mp4
```
معاينة حية في المتصفح: افتح `film/index.html?play`.
